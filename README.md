# Cartridge Scanner - клиентская часть на Android (терминал сбора данных)
Приложение Cartridge Scanner устанавливается на Android устройство со встроенным сканером (тестилось на Android версии 9)
Предполагается, что Android устройство оборудовано встроенным сканером, по центру экрана находится поле ввода для штрих-кода.
Обмен данными с веб-сервером выполняется в одном из 3 режимов:
- Добавление (Приход) POST: запрос об изменении состояния картриджа по определенному штрих-коду
- Удаление (Расход) POST: запрос об изменении состояния картриджа по определенному штрих-коду
- Чтение (Инфо) GET: запрос о состоянии картриджа по определенному штрих-коду

Поскольку сырой http трафик передается в незашифрованном виде, перед тем как отправить POST, ТСД шифрует отправляемое json-сообщение алгоритмом AES. Аналогично, принятый ответ от сервера сначала расшифровывается. 

Интересно реализована защита от reply-атаки: если стащить сетевым снифером данные, отправляемые от ТСД к серверу, сохранить их и вручную (например с помощью curl) попытаться отправить их самостоятельно - сервер отбросит его. Когда ТСД формирует пакет, к json данным он добавляет уникальный айдишник пакета и задает ему TTL в 10 секунд. 

Сервер временно (каждый час происходит очистка сета) хранит сет всех обработанных пакетов:
1. Если пакет с таким id уже есть в сете, он отбрасывается
2. Если пакет просрочен - он отбрасывается.
3. В итоге получаем 100% гарантию того, что пакет отправленный от ТСД (даже если его сперли сетевые воры) дойдет до сервера в единичном экземпляре.

При смене ключа шифрования или пин-кода нужно пересобрать apk!
- Ключ шифрования AES_KEY прописан в конфиге на серверной части и в коде приложения для Android.
- Пин-код приложения для ТСД прописан в коде приложения для Android.

# Cartridge Master - серверная часть, веб-приложение для учёта картриджей.
Приложение состоит из 2 компонент: 
* Uvicorn-Web-Server
* Caddy-Reverse-Proxy
### Caddy
* Магия легкого https: поскольку публичный Let's Encrypt не может проверить локальные адреса, Caddy автоматически запускает внутри себя миниатюрный локальный центр сертификации. Достаточно установить на устройстве root.crt которые генерит caddy в доверенные (срок 10 лет) и забыть про варнинг незащищенное соединение, когда оно фактически защищено. 
* Обеспечивает пересылку HTTPS трафика (443 порт) на HTTP (8080) бэкенда.
* Блокирует входящий HTTP трафик
* Пропускает по HTTP только шифрованные запросы от ТСД
### Веб-сервер на Uvicorn
Веб-сервер (асинхронный, uvicorn) работает на 8080 порту. 
Обрабатывает REST-запросы и выполняет заложенную логику - раздача фронта, работа с БД, работа с шифрованием, сессиями, ldap, почтовым сервером.
Используется легковесный фреймворк FastAPI для быстрого создания эндпоинтов.
Бэкенд на python (3.11), фронтенд на js

### База данных
Используется локальная БД SQLite - database.db. Хранится в корне.   
Состоит из нескольких таблиц перечисленных ниже. 

Таблица cartridges.

Связана с barcodes связью один ко многим:
| id | cartridge_name | quantity |  min_qty |   last_update      | quantity_reserve |
|----|----------------|----------|----------|--------------------|------------------|
| 1  | Имя_картриджа_1 |     5   |     0    |2026-02-18 14:03:43  |         0       | 
| 2  | Имя_картриджа_2 |     2   |     1    |2026-02-18 14:03:44  |         1       |

Таблица barcodes. 

Столбец cartridge_id ссылается на первичный ключ id из первой таблицы cartridges.
| barcode | cartridge_id |
|----------------|---|
| 4004764390564  | 1 |
| 1234567891121  | 1 |
| 1234567891111  | 2 |

Таблица emails. 

Содержатся все добавленные адреса для уведомлений.
| id | email_adress        | norifications_on |
|----|---------------------|-------------------|
| 1  |  example@email.com  |           1       |

Таблица history. 

Запись всех совершенных операций (через веб-интерфейс и от ТСД) за всё время.
| increment | cartridge_id | cartridge_name |  delta |   editor                            | created_at           |  editor |
|-----------|--------------|----------------|--------|-------------------------------------|----------------------|---------|
| 1         | 1            |     TS123-1    |     1  |  Platform: Windows       10.0.12.77 | 2026-02-18 14:03:43  |   surname@domain.internal      |
| 2         | 2            |     TS123-2    |     -2 | Platform: Mobile/Other  10.0.23.194 | 2026-02-18 14:03:44  |   localuser@local    |

Таблица sessions. 

Хранятся все активные пользовательские веб-сессии. Middleware пропускает без проверки только login (для атворизации) и статические файлы, а каждый API-запрос проверяется с извлечением session_id из куки авторизованного пользователя. Срок действия сессии - 7 дней, протухшие автоматически очищаются.
| session_id | user_dn | created_at |  expires_at |
|----|----------------|----------|----------------|
| ba654657-7c77-4a08-a925-6ce31a0ada65  | localuser@local |     2026-09-08 20:23:26   |     2026-09-15T23:23:26.967616    |

Таблица settings. 

Для настройки расписания уведомлений - автоотправка на email о низком запасе расходников.
| key                    | value |
|------------------------|-------|
| notifications_enabled  | True |
| notification_days      | 1,2,3,4,5,6 |
| notification_time      | 12:00 |
